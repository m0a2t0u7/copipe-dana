# ラテコピペ

タップでコピーして元のアプリへ戻る、Android用の定型文アプリ。

## できること
- 名前つき定型文（名前が空なら本文1行目を見出しに表示）
- 長文はプレビュー0〜5行に制限し、▼で全文展開
- フォルダ階層、パンくず、ピン留め（トップにも表示）
- タップ・長押し・ダブルタップの動作を設定で切替
- コピー時にカードが光り、画面下に「コピーしました」を表示
- テーマ（端末／ライト／ダーク）、アクセント色6色、文字サイズ3段階
- `[ツール名]` のような角かっこを穴埋め入力してからコピー
- 全フォルダ検索、並び順（作成順・最近・よく使う・名前）
- クイック設定タイル、共有メニュー、テキスト選択メニューから登録
- JSONバックアップの書き出し・取り込み、テキスト取り込み（`---` 区切りで複数件）

## ビルド
GitHubにpushすると Actions が署名済みAPKを作り、Releases の「最新版」に置きます。

## アイコン
案A「定番コピー」を採用：濃紺の背景に白い書類が重なるシンプルなアイコン。
アプリ名とアイコンのみの更新では、アプリID・署名・既存の保存データ形式を変更しません。旧バージョンへ上書きインストールできます。
